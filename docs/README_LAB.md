SOC Homelab — Security Onion (SO2) + Wazuh + Sysmon + Zeek

Overview
- Purpose: Build a small SOC homelab to practice alert triage, cross-log correlation, escalation, and packet analysis.
- Components: Security Onion 2 (SIEM), Windows VM (Sysmon + Wazuh agent), Linux VM (Zeek), Kibana dashboards, Wireshark for packet capture, ChatGPT prompts for AI-assisted analysis.

Recommended VM specs
- Security Onion 2: 8-12 GB RAM, 4 vCPU
- Windows 10/11 VM: 4 GB RAM, 2 vCPU
- Linux (Zeek): 2-4 GB RAM, 2 vCPU

Directory layout in repo
- docs/: diagrams, screenshots, reports
- scripts/: install helpers (Security Onion, Zeek, Wazuh)
- kibana/: dashboard JSON samples
- evidence/: screenshots and exported artifacts

Quick start (high level)
1. Provision VMs (local hypervisor / cloud). Ensure network between them.
2. Deploy Security Onion on a dedicated VM. Run: `sudo so-install` then `sudo so-status`.
3. Configure Wazuh manager/agent integration or connect Windows Wazuh agents to SO.
4. Install Sysmon on the Windows VM and deploy SwiftOnSecurity configuration.
5. Install Zeek on Linux VM; forward logs to SO or store locally and use Kibana to ingest if desired.
6. Open Kibana on Security Onion: https://<SO-IP>
